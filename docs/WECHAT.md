# 微信小游戏上架材料包

> 本文所有结论均对照微信官方文档核实（2026-10）。
> 官方入口：[小游戏接入指南](https://developers.weixin.qq.com/minigame/introduction/guide/)

---

## 一、先给你吃个定心丸：IAA 游戏通常**不需要软著**

官方《[资质审核-IAA](https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html)》原文：

> IAA 游戏进行备案时，**遇以下情形**需要提交《计算机软件著作权登记证书》或对应其他授权材料：
> 1）游戏名称含有**英文**、或"**软件**"字样
> 2）涉及相关**品牌、公众人物合作**等

**结论：只要满足这两个条件，就能绕开软著**

- ✅ 游戏名称**纯中文**，不带任何英文字母
- ✅ 名称里**不含"软件"**二字
- ✅ 不做任何品牌联动、不用公众人物形象

> ⚠️ 反面教材：叫「**Jump** 跳一跳」或「跳跃**软件**」→ 立刻触发软著要求。所以下面推荐的名字全是纯中文。

## 二、完整发布流程（IAA）

📖 [IAA 游戏发布指引（官方）](https://developers.weixin.qq.com/minigame/introduction/guide/iaa.html)

```
注册账号 → 名称/简称/头像 → 类目设置 → 微信认证 → 适龄提示
        → 资质审核 → 版本审核 → 小游戏备案 → 小程序备案 → 发布
```

**官方给出的时效：IAA 游戏 13~37 个工作日**（IAP 是 9~22 个工作日，比 IAA 快，但我们要开通虚拟支付，不合适）。

几个能省时间的关键点（官方明示）：

- 名称、简称、头像、类目、微信认证 **可以并行**
- **版本审核 与 资质审核 可以并行**（文化互动类除外）
- **小游戏备案 与 小程序备案 可以并行提交**
- 游戏开发 **不占审核时间**，可以同时进行

> 官方特别提醒：**小游戏发布前，必须先完成「版本审核」和「备案」两个流程。**

### 3.1 名称 / 简称

📖 [名称、简称 & 图标设置（官方）](https://developers.weixin.qq.com/minigame/introduction/guide/name.html)
📖 [小程序名称、简称设置规范](https://kf.qq.com/faq/170109umMvm6170109MZNnYV.html)

**规则**

| 项 | 规则 |
|---|---|
| 名称长度 | 4~30 字符，**1 个中文 = 2 字符** → 2~15 个汉字 |
| 名称唯一性 | 名字唯一；**不得与不同主体的公众号重名**；同主体下小程序和公众号可同名 |
| 简称长度 | 4~10 字符 → 2~5 个汉字，**必须从名称中按顺序截取** |
| 改名次数 | 境内账号每个自然年 **2 次** |

**推荐填写**

| 字段 | 填什么 | 字符数 |
|---|---|---|
| **名称** | `跳跳小光` | 8 字符（4 汉字）✅ |
| **简称** | `跳跳小光` | 8 字符（简称与名称相同也允许）✅ |

> 名称一旦提交就定了。如果后台最终用的不是「跳跳小光」，

> 提审截图里必须能看到和小游戏**一字不差**的名字。

备选名称（被占用就依次换）：`方块跃迁记`、`蓄力方块`、`方块登高记`、`方块跳台阶`、`跃跃方块`、`一拍一跳`

| 现象 | 原因 | 处理 |
|---|---|---|
| 提交后被打回「适龄等级与内容不符」 | 画面其实偏写实却选了 8+ | 本项目不涉及 |

```text
本次为首个正式版本（1.0.1）。
```

**写法要点**（以后每个版本照这个格式改）

| 规则 | 说明 |
|---|---|
| 开头一句写清版本号 | 「本次为 1.0.2 版本」；首版写「首个正式版本」 |
| 每条用「新增 / 优化 / 修复」开头 | 审核员按关键词扫读，纯叙述段落容易被判「描述不清」 |
| **只写真实存在的东西** | 文案里每条都能在代码里找到（见下表核对） |
| 不要写「优化体验」「修复若干问题」这类空话 | 会被要求补充具体说明 |
| 不要提未上线功能 | 写「即将上线排行榜」会被当成功能缺失驳回 |
| 字数控制在 200~280 | 太短信息量不够，贴到 300 会被截断 |

**文案与代码的对应关系（改功能时同步改这段）**

| 文案条目 | 代码位置 |
|---|---|
| 蓄力 / 起跳 / 跳跃距离 | `src/main.ts`（触摸绑定 `charge`/`release`）、`src/core/game.ts`（`startCharge`/`releaseCharge`） |
| 落点判定、完美双倍、连击 | `src/core/game.ts`（`state.combo`、`perfect` 判定） |
| 难度递进（平台收窄、间距加大） | `src/core/game.ts` 的 `addPlatform()` |
| 最高分本地保存 | `src/main.ts`（`BEST_KEY = 'dyjump:best'`） |
| 单局最多复活 2 次 | `src/core/constants.ts`（`MAX_REVIVES = 2`） |
| 震动反馈 | `src/main.ts` 的 `platform.vibrate('heavy' / 'light')` |

### 3.10 游戏引擎怎么选（「游戏设置」页）

本项目是**原生 TypeScript + Canvas 自研渲染**，没有用任何第三方引擎：

```bash
# 依赖里只有构建工具，没有引擎
"dependencies": {}
"devDependencies": { "miniprogram-ci": "^2.1.31" }

# dist/wx/game.js 里搜不到 cocos / laya / egret / unity / pixi
# 整个包 20KB，引擎随便一个都 1MB 起
```

所以**不要选 Cocos / Laya / Unity / Egret**。后端下拉框里找最接近的一项，常见叫法：

- **「其他」** ← 最稳，一般不追问
- 「自研引擎」/「自研框架」
- 「无」/「不使用引擎」/「原生 Canvas」

按后台实际显示的选项选，选「其他」类的即可。

**为什么不能乱选**：选了 Cocos/Laya 这类，表单通常会跟着要**引擎版本号**（如 `3.8.2`），
而你填不出来；真填了，审核看到代码里没有任何引擎 Runtime，属于信息不实，反而更麻烦。

> 补充：微信对「使用官方框架」这类勾选项，如果问的是**是否使用微信官方提供的小游戏适配框架**
> （`weapp-adapter` / `minigame-canvas`），本项目也没有用——我们直接调 `wx.createCanvas()`
> 和 `wx.onTouchStart()`，不依赖任何 adapter。所以这类问题一律选「否 / 未使用」。

## 六之二、广告接入：代码已完成，只差一个 ID

这一节回答「广告到底怎么接」。结论先给：**该写的代码全写完了**，
你不需要改一行代码，只需要在流量主开通后把 `adunit-xxxxxxxx` 填到 `config.ts` 第 12 行。

### 6C.1 广告代码的完整链路（已实现）

```
玩家坠落 → 结算页点「看视频复活」（layout.ts 生成 revive 按钮）
        ↓
main.ts requestRevive() 把 phase 切成 adLoading（期间画出「加载中」）
        ↓
ads.ts showRewardedAd()
        ↓ 读取 config.wxRewardedAdUnitId
        ↓ 为空 → 直接返回 completed（免费复活，见 6C.3）
        ↓ 非空 → 交给平台适配器
platform/wx.ts → platform/ad-channel.ts
        ↓ 复用同一个 RewardedVideoAd 实例
        ↓ show() 失败先 load() 再 show()
wx.createRewardedVideoAd({ adUnitId })
        ↓
onClose(res) → res.isEnded === true ? 'completed' : 'skipped'
onError()    → 'failed'
        ↓
只有 'completed' 才 revive(game)，其余回到 dead 状态
```

**关键文件**

| 文件 | 作用 |
|---|---|
| [`src/config.ts`](./../games/jump/src/config.ts) | 广告位 ID 与调试开关的唯一入口 |
| [`src/ads.ts`](./../games/jump/src/ads.ts) | 分流微信/抖音广告位、决定是否放行 |
| [`src/platform/ad-channel.ts`](./../games/jump/src/platform/ad-channel.ts) | 激励视频实例复用、预加载、看完判定 |
| [`src/platform/wx.ts`](./../games/jump/src/platform/wx.ts) | 绑定 `wx.createRewardedVideoAd` |
| [`src/main.ts`](./../games/jump/src/main.ts) | 启动时 `preloadRewardedAd()`，复活按钮走 `requestRevive()` |

### 6C.2 已经处理掉的四个坑

| 坑 | 不处理的后果 | 现在的做法 |
|---|---|---|
| 每次点击都 `createRewardedVideoAd` | 第二次之后 `show()` 一直失败，玩家点复活没反应 | 实例只创建一次，之后复用（`ad-channel.ts`） |
| 不预加载，点击时才拉广告 | 黑屏等 1~3 秒，这段流失率极高 | 启动时 `preloadRewardedAd()` 提前 load |
| `show()` 失败直接判定失败 | 首次播放必然失败（官方要求先 `load()`） | 失败后自动 `load().then(show)` 重试一次 |
| 没看广告也算完成 | 平台判定「激励视频未观看即发奖」，属违规 | 只有 `res.isEnded === true` 返回 `completed` |

### 6C.3 广告位为空时的行为（当前状态）

`wxRewardedAdUnitId` 还是空字符串，此时：

- 启动时**不**发起任何广告请求（避免无效请求）
- 点「看视频复活」**立即**复活，不播广告
- 结算页照常显示「看视频复活」按钮

这是刻意的降级：流量主要 UV 满 1000 才能开通，这段空窗期若返回 `failed`，
按钮点了毫无反应，玩家会以为游戏卡死。**填入 ID 后自动切换到真实广告**，无需改代码。

> ⚠️ 提审时如果审核员点「看视频复活」发现没播广告，可能留言问询。
> 回复「广告位待流量主开通后配置，功能已按平台规范接入」即可，不影响过审。

### 6C.4 你需要做的三步（等流量主开通后）

**① 后台创建广告位**

公众平台 → 左侧「流量主」→ 开通后进入「广告位管理」→ 新建广告位：

| 字段 | 填什么 |
|---|---|
| 广告位类型 | **激励视频** |
| 广告位名称 | `跳跳小光-复活`（自己看得懂即可） |
| 适用场景 | 单局失败后复活 |

创建完成后列表里会出现一串 `adunit-` 开头的 ID，**整串复制**。

**② 填进配置**

打开 [`games/jump/src/config.ts`](./../games/jump/src/config.ts) 第 12 行：

```ts
wxRewardedAdUnitId: 'adunit-xxxxxxxxxxxxxxxx',
```

> 只填 `adunit-` 后面那串是不够的，**前缀必须带上**。
> 构建脚本会校验格式，填错会直接报「格式不对」并中止，不会打包出一个畸形产物。

**③ 重新构建上传**

```bash
cd ~/workspace/Game/DouyinGame
npm run build -w games/jump
npm run upload -w games/jump -- 1.0.2 "接入激励视频广告"
```

### 6C.5 怎么验证广告真的接通了

不要靠「感觉」，按这个顺序看：

| 检查项 | 方法 | 正常表现 |
|---|---|---|
| 代码里 ID 生效 | `grep adunit games/jump/dist/wx/game.js` | 能搜到你填的那串 |
| 调试开关已关 | `grep debugFakeAd games/jump/dist/wx/game.js` | 显示 `debugFakeAd:!1` |
| 真机能否播放 | 微信开发者工具扫码 → 故意坠落 → 点「看视频复活」 | 弹出真实视频广告 |
| 看完是否发奖 | 完整看完 15/30 秒 | 回到坠落前平台继续玩 |
| 中途关闭是否拦 | 广告播 3 秒就点 × 关闭 | **不**复活，回到结算页 |
| 收益是否产生 | 流量主后台 → 数据统计 → 次日看 | 有曝光与收益记录 |

> 广告刚创建后通常需要 **1~2 小时**才生效，刚填完立刻测可能拉不到，属正常现象。

## 七、微信端审核红线（比抖音更严的几条）

1. **不能强制观看广告**，不能「不看广告就不让玩」
2. **首屏不能弹插屏广告**
3. **必须配置用户隐私保护指引**（即使不收集信息也要声明，这是提审必填项）
4. **必须完成适龄提示设置**，否则提审提交不了
5. 有用户可输入内容时必须接内容安全接口（本项目无输入，不涉及）
