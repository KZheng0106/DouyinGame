# 微信小游戏上架材料包

> 本文所有结论均对照微信官方文档核实（2026-10）。
> 官方入口：[小游戏接入指南](https://developers.weixin.qq.com/minigame/introduction/guide/)

---

## 一、先给你吃个定心丸：IAA 游戏通常**不需要软著**

官方《[资质审核-IAA](https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html)》原文：

> IAA 游戏进行备案时，**遇以下情形**需要提交《计算机软件著作权登记证书》或对应其他授权材料：
> 1）游戏名称含有**英文**、或"**软件**"字样
> 2）涉及相关**品牌、公众人物合作**等

**结论：只要满足这两个条件，就能绕开软著**

- ✅ 游戏名称**纯中文**，不带任何英文字母
- ✅ 名称里**不含"软件"**二字
- ✅ 不做任何品牌联动、不用公众人物形象

> ⚠️ 反面教材：叫「**Jump** 跳一跳」或「跳跃**软件**」→ 立刻触发软著要求。所以下面推荐的名字全是纯中文。

## 二、完整发布流程（IAA）

📖 [IAA 游戏发布指引（官方）](https://developers.weixin.qq.com/minigame/introduction/guide/iaa.html)

```
注册账号 → 名称/简称/头像 → 类目设置 → 微信认证 → 适龄提示
        → 资质审核 → 版本审核 → 小游戏备案 → 小程序备案 → 发布
```

**官方给出的时效：IAA 游戏 13~37 个工作日**（IAP 是 9~22 个工作日，比 IAA 快，但我们要开通虚拟支付，不合适）。

几个能省时间的关键点（官方明示）：

- 名称、简称、头像、类目、微信认证 **可以并行**
- **版本审核 与 资质审核 可以并行**（文化互动类除外）
- **小游戏备案 与 小程序备案 可以并行提交**
- 游戏开发 **不占审核时间**，可以同时进行

> 官方特别提醒：**小游戏发布前，必须先完成「版本审核」和「备案」两个流程。**

## 三、可以直接抄的文案（逐字段）

### 3.1 名称 / 简称

📖 [名称、简称 & 图标设置（官方）](https://developers.weixin.qq.com/minigame/introduction/guide/name.html)
📖 [小程序名称、简称设置规范](https://kf.qq.com/faq/170109umMvm6170109MZNnYV.html)

**规则**

| 项 | 规则 |
|---|---|
| 名称长度 | 4~30 字符，**1 个中文 = 2 字符** → 2~15 个汉字 |
| 名称唯一性 | 名字唯一；**不得与不同主体的公众号重名**；同主体下小程序和公众号可同名 |
| 简称长度 | 4~10 字符 → 2~5 个汉字，**必须从名称中按顺序截取** |
| 改名次数 | 境内账号每个自然年 **2 次** |

**推荐填写**

| 字段 | 填什么 | 字符数 |
|---|---|---|
| **名称** | `跳跳小光` | 8 字符（4 汉字）✅ |
| **简称** | `跳跳小光` | 8 字符（简称与名称相同也允许）✅ |

> 名称一旦提交就定了。如果后台最终用的不是「跳跳小光」，
> 把 [`src/config.ts`](./../games/jump/src/config.ts) 里的 `gameName` 改成实际名称，
> 再跑 `npm run build -w games/jump && npm run shots -w games/jump` 重新出截图即可——
> 提审截图里必须能看到和小游戏**一字不差**的名字。

备选名称（被占用就依次换）：`方块跃迁记`、`蓄力方块`、`方块登高记`、`方块跳台阶`、`跃跃方块`、`一拍一跳`

> 全部为纯中文，**且不含英文、不含"软件"** → 不触发软著要求。

### 3.3.1 游戏类型 / 网络类型

| 字段 | 填什么 |
|---|---|

**详细介绍（可直接粘贴）**

> 《跳跳小光》是一款单指操作的休闲跳跃小游戏。按住屏幕蓄力，松开后小方块向前跳跃，落在下一块平台上即可得分，落在平台正中央可额外获得双倍分数并累积连击。跳跃距离越远、落点越准，分数越高。落空坠落即本局结束，可通过观看激励视频复活一次继续挑战，也可随时重新开始。单局几十秒，随时可玩，最高分自动保存。

## 六、你接下来要做的（按顺序）

### 第 1 步：拿到 AppID

微信公众平台 → 左侧 **「开发 → 开发管理 → 开发设置」** → 最上面的 **AppID(小程序ID)**，
形如 `wx` + 16 位十六进制。

📖 [开发设置页面](https://mp.weixin.qq.com/wxamp/devprofile/get_profile)

拿到后**发我**，或者自己一条命令写进配置：

```bash
npm run appid -w games/jump -- wx1234567890abcdef
```

### 第 2 步：装微信开发者工具，导入 `games/jump/dist/wx/`

📖 [微信开发者工具下载](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)

下载后选「稳定版 Stable Build」，装完用**微信扫码登录**（必须是这个 AppID 的管理员微信号）。

**关于「能不能帮我直接传」**：不行。上传代码这一步走的是你本机的微信开发者工具 +
你的微信登录态，代码传到你自己的小程序账号下。我没有办法操作你电脑上的 IDE，
也没有你的微信登录会话。所以这一步只能你点，但我已经把要做的准备全做完了：

```bash
# 1) 填 AppID（wx 开头 18 位，后台「开发 → 开发管理 → 开发设置」里拿）
npm run appid -w games/jump -- wx1234567890abcdef

# 2) 重新构建，把 AppID 写进 dist/wx/project.config.json
npm run build -w games/jump
```

**导入步骤**（工具里一共 4 下点击）：

1. 打开微信开发者工具 → 左侧选「小程序」→ 点右上角 **`+`（导入项目）**
2. **目录**：选到 `games/jump/dist/wx`（是 `dist/wx` 这一层，不是仓库根目录）
3. **AppID**：会自动从 `project.config.json` 读出来；读不到就手动粘贴
4. 点「导入」→ 模拟器里应该立刻出现「跳跳小光」开始页

> 导入后如果提示 `game.json` 里的 `deviceOrientation` 之类警告，可以忽略，不影响上传。

### 第 3 步：上传体验版（对应后台「第二步：版本管理」）

工具**右上角**的按钮条上，从左到右是「预览 / 真机调试 / 上传」——点 **「上传」**。

弹出的小窗里填两项：

| 字段 | 填什么 |
|---|---|
| 版本号 | `1.0.0` |
| 项目备注 | `首个版本：跳跃核心玩法、落点判定与连击计分、激励视频复活` |

点「上传」→ 等进度条走完 → 出现「上传成功」即可关掉。

然后回到浏览器里的微信公众平台：

1. 左侧菜单 **「管理 → 版本管理」**（就是你截图那一页）
2. 「开发版本」区域里会出现刚传的 `1.0.0`，点右侧 **「选为体验版本」** → 生成体验版二维码
3. 用自己的微信扫这个码，**真机跑一遍**：开始页名字对不对、蓄力手感、复活有没有真的播广告
4. 手机试玩没问题，再回到「开发版本」点 **「提交审核」**

📖 [上传与版本管理（官方）](https://developers.weixin.qq.com/minigame/introduction/guide/banben.html)

> 上传失败的常见原因就三个：① AppID 没对应该账号；② 目录选错（选成仓库根目录，找不到 `game.json`）；
> ③ 当前登录的微信号不是该小程序的管理员/开发者。

### 第 4 步：并行推进三件事（官方允许并行）

- [ ] **名称/简称/头像/类目** 设置
- [ ] **微信认证**（官方原文：企业主体必须认证才能提交小程序备案；个人主体按后台提示）
- [ ] **资质审核**（IAA → 情况二 → 纯中文名 → 无需软著）

### 第 5 步：提前准备备案材料

📖 [小程序备案（官方)](https://developers.weixin.qq.com/minigame/introduction/guide/xcxba.html)

个人主体备案通常需要：身份证正反面、手机号、邮箱、应急联系人信息。**这是整个流程耗时最长的一环，越早越好。**

### 第 6 步：版本审核

📖 [版本审核（官方)](https://developers.weixin.qq.com/minigame/introduction/guide/bbsh.html)

「版本管理 → 开发版本 → 提交审核」，需完成：选引擎、填隐私保护指引、完成适龄提示、填版本说明、苹果开发者账号（可填邮箱）。

### 第 7 步：开通流量主（IAA 变现）

📖 [激励视频广告（官方）](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/ad/rewarded-video-ad.html)

小游戏发布后，在公众平台「推广 → 流量主」申请开通（有用户量门槛，**具体以后台提示为准**），再创建激励视频广告位，把 `adunit-xxx` 发我。

**开通后必须做**：把 `games/jump/src/config.ts` 的 `debugFakeAd` 改成 `false`，否则用户不看广告也能复活。

## 七、微信端审核红线（比抖音更严的几条）

1. **不能强制观看广告**，不能「不看广告就不让玩」
2. **首屏不能弹插屏广告**
3. **必须配置用户隐私保护指引**（即使不收集信息也要声明，这是提审必填项）
4. **必须完成适龄提示设置**，否则提审提交不了
5. 有用户可输入内容时必须接内容安全接口（本项目无输入，不涉及）
